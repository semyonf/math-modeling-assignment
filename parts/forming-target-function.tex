    \section*{Целевая функция}
        \begin{center}
            Целевая функция 2: $CF(k, b_1) = \sum\limits_{i=1}^{25}\left(y^{\text{Э}}(t_i) - y^{M}(t_i; k, b_1)\right)^2$
        \end{center}

        Неизвестными являются параметры $k$ и $b_1$. Модельные значения $y^M$ вычисляются тем же методом, что и $y^T$ в части 1, при текущих значениях $k$, $b_1$; остальные параметры ($a$, $b_2$, $x$) известны. Минимум $CF$ ищется методом $GZ_1$ из части 2 из начальной точки $k = 5$, $b_1 = 2$.

        Оптимизация выполняется для трёх экспериментальных функций $y^{\text{Э}_1}, y^{\text{Э}_2}, y^{\text{Э}_3}$. В результате получаются три пары оценок неизвестных параметров. Истинные значения $k = 4$, $b_1 = 1$ известны, поэтому для каждой оценки можно указать относительную погрешность $\delta$.

        Опыты имеют разную точность: дисперсия равномерного шума равна $\Delta y^2/3$ и при уровне $20\%$ в $16$ раз больше, чем при $5\%$. Простое среднее даёт всем опытам одинаковый вес, и самый шумный опыт ухудшает результат. Поэтому, помимо среднего, вычисляется среднее, взвешенное обратно пропорционально дисперсии шума:
        $$
            \hat\theta = \sum_{j=1}^3 w_j \hat\theta_j, \qquad
            w_j = \frac{1/\Delta y_j^2}{\sum_l 1/\Delta y_l^2}, \qquad
            w = (\WeightA;\ \WeightB;\ \WeightC).
        $$

    \section*{Статистика оценок}
        Результат одного опыта случаен: при другой реализации шума оценки будут другими. Чтобы оценить точность метода, а не отдельного опыта, весь эксперимент (генерация шума и оптимизация) повторён $\MonteCarloRuns$ раз.     \section*{Выводы четвёртой части}
        \begin{itemize}
            \item Средние значения оценок совпадают с истинными ($k = 4$, $b_1 = 1$) в пределах статистической погрешности, то есть систематической ошибки метод не даёт. Это подтверждает и правильность реализации модели и оптимизации.
            \item Разброс оценок растёт примерно пропорционально уровню шума: при увеличении шума вдвое СКО тоже увеличивается примерно вдвое.
            \item Относительная погрешность $k$ в несколько раз меньше, чем у $b_1$: $k$ задаёт установившееся значение, по которому есть много наблюдений, а $b_1$ влияет только на форму переходного процесса.
            \item Простое среднее трёх опытов оказывается менее точным, чем оценка по одному наименее зашумлённому опыту. Взвешенное среднее учитывает разную точность опытов и даёт наименьший разброс.
        \end{itemize}
