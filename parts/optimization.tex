\part{ОПТИМИЗАЦИЯ}
    Метод Гаусса-Зейделя ($GZ_1$) сводит задачу поиска минимума функции нескольких переменных к последовательности одномерных шагов: на каждом шаге меняется только одна координата, остальные фиксированы, координаты перебираются циклически.

    \section*{Алгоритм метода оптимизации $GZ_1$}
        \begin{center}
            \includegraphics[scale=0.7]{img/gz1-alg}
        \end{center}
        По каждой координате $x_m$ делается пробный шаг $h_m$. Если значение функции не увеличилось, шаг принимается и утраивается ($h_m := 3h_m$). Иначе шаг отменяется, уменьшается вдвое и меняет направление ($h_m := -0.5h_m$). Начальный шаг $s = 0.1$.

        Критерий останова: модули шагов по всем координатам стали меньше $\varepsilon = 10^{-6}$. Около минимума любой пробный шаг неудачен, и шаги быстро уменьшаются. Сравнивать для останова два соседних пробных значения функции нельзя: они могут оказаться близкими далеко от минимума, например в самом начале поиска на вытянутой функции. Для защиты от зацикливания число циклов ограничено ($10^5$).

    \section*{Проверка работоспособности}
        Тестовые функции подобраны так, чтобы координатный метод не мог найти минимум случайно: у обеих линии уровня вытянуты и не параллельны осям координат. Траектории построены той же программой и с тем же критерием останова, что используется при идентификации.

        \subsection*{Эллиптический параболоид $f = 5x^2 + 8xy + 5y^2$}
            Оси эллипсов линий уровня повёрнуты на $45^\circ$, отношение полуосей $1:3$. Минимум $f(0;0) = 0$, начальная точка $(4;3)$.

            Найдена точка $(\EllipseX;\ \EllipseY)$, $f = \EllipseF$, за $\EllipseCycles$ циклов.

        \subsection*{Функция Розенброка $f = (1 - x)^2 + 100(y - x^2)^2$}
            Минимум $f(1;1) = 0$ лежит на дне узкого изогнутого оврага. Начальная точка -- стандартная $(-1.2;1)$.

                \end{axis}
            \end{tikzpicture}
            \end{center}
            Пунктиром показано дно оврага $y = x^2$. Найдена точка $(\RosenbrockX;\ \RosenbrockY)$, $f = \RosenbrockF$, за $\RosenbrockCycles$ циклов.

        В обоих случаях метод сходится к известному минимуму. На функции Розенброка видна характерная слабость координатного спуска: шаги, параллельные осям, плохо следуют изогнутому оврагу, поэтому требуются тысячи циклов. Целевая функция идентификации устроена проще (это видно по траекториям в части 4), и там хватает нескольких десятков циклов.
